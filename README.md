# ApexBank - Modern Fintech Landing Page

A responsive, modern frontend landing page for a fictional digital banking platform called **ApexBank**. This project was built as part of my technology portfolio during my NYSC service year to demonstrate core frontend development capabilities.

## ✨ Features
*   **Responsive Navigation:** Adaptive header optimized for both desktop and mobile screens.
*   **Fintech Hero Section:** Clean call-to-action layout focusing on user conversion metrics.
*   **Product Highlight Grid:** Structured showcase cards highlighting instant transfers, security features, and analytics.

## 🛠️ Tech Stack
*   **HTML5:** Semantic markup structure.
*   **CSS3:** Custom layout styling, flexbox grids, transitions, and media queries for responsiveness.

## 📂 Project Structure
*   `index.html` - The structural content of the web platform.
*   `style.css` - Custom styling rules and structural layouts.
